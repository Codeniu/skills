# My Skills

个人技能开发仓库

**仓库地址**: [https://github.com/Codeniu/skills.git](https://github.com/Codeniu/skills.git)

安装命令：

```shell
npx skills add https://github.com/Codeniu/skills --skill geometric-art-poster
```
