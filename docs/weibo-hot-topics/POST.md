# 【Skill 创作】微博热搜榜 - 一键获取实时热点资讯

## 1、Skill简介

这是一个能够实时获取微博热搜榜前十的 Skill，无需 API Key，直接调用即可获取最新热点资讯。适合需要快速了解网络热点、追踪舆情动态的内容运营、市场研究人员或普通用户使用。

## 2、使用场景

### 为什么想做它？

在信息爆炸的时代，了解当下的热点话题变得越来越重要。无论是内容创作者寻找选题素材，还是市场人员追踪舆情，又或者是普通用户想快速了解当天最热话题，手动去微博查看热搜既费时又不方便。

### 之前遇到了什么麻烦？

- 想要了解当前热点，需要打开微博 App 或网页，登录后找到热搜入口，操作繁琐
- 热点更新快，经常需要反复刷新查看
- 无法快速获取结构化的热搜数据，不利于后续分析和使用
- 有些场景下需要程序化获取（比如自动推送、定时汇总等）

### 做出来之后能省掉哪些动作？

- 无需打开浏览器或 App，一句指令即可获取最新热搜
- 自动格式化输出，表格形式清晰易读
- 可程序化调用，支持定时任务、自动化流程
- 数据结构化，便于后续分析和处理
- 零配置，无需注册账号或申请 API Key

## 3、创作过程

### 灵感来源

在日常工作和生活中，我经常需要了解微博热搜来把握舆论方向。但每次都要：
1. 打开微博
2. 找到热搜入口
3. 手动浏览
4. 关闭页面

这个过程重复且低效。我就想，为什么不能让 AI 直接告诉我现在的热搜是什么呢？

### 使用 SOLO 的创作步骤

1. **需求分析**：确定核心需求——获取微博热搜榜前十，格式清晰，无需认证
2. **API 调研**：搜索无需 API Key 的微博热搜 API，最终选择了 v2.xxapi.cn
3. **功能设计**：设计返回数据结构（排名、标题、热度等）
4. **输出优化**：从最初的详细格式逐步简化为 Markdown 表格，只保留排名和标题
5. **异常处理**：添加备用数据机制，确保 API 不可用时也能返回示例数据
6. **测试验证**：多次调用测试，确保输出格式正确

### 关键配置

```yaml
name: "weibo-hot-topics"
description: "获取微博热搜榜单，按热度排序。无需 API Key。使用真实 API 获取实时数据。"
API_URL: "https://v2.xxapi.cn/api/weibohot"
```

### 技术架构

- **数据获取**：使用 Python requests 库调用 REST API
- **数据解析**：提取 title 和 hot 字段
- **格式输出**：使用 Markdown 表格格式，支持中文显示
- **异常处理**：try-except 捕获网络异常，自动返回备用数据

## 7、总结与思考

### 收获与感悟

创建这个 Skill 的过程让我深刻体会到：

1. **效率提升显著**：从手动操作的分钟级到 AI 调用的秒级，体验完全不一样
2. **工具思维的重要性**：很多重复性的信息获取任务，都可以通过 Skill 自动化
3. **API 资源挖掘**：互联网上有很多优质的免费 API，关键是要善于发现和使用
4. **极简设计原则**：去掉不必要的元素（摘要、链接），只保留核心信息，反而更实用

### 最满意的地方

最满意的是整个 Skill 的极简设计理念。只保留排名和标题，去掉了摘要和链接，让输出更加清爽、直接。这符合"少即是多"的设计原则——用户真正需要的，往往就是那最关键的几列信息。

### 后续优化方向

1. **增加热度显示**：虽然目前简化了输出，但热度信息对判断话题热度很有价值，考虑加回热度列
2. **自定义排名数量**：支持获取前 N 条热搜，不仅仅是前十
3. **定时推送功能**：结合 SOLO 的 Schedule 功能，实现每日定时推送热搜到指定渠道
4. **历史记录**：支持查询历史热搜，分析话题趋势变化
5. **多平台支持**：扩展到抖音热搜、知乎热榜等其他平台
