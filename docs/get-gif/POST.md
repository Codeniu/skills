# 【Skill 创作】一个帮你快速搜索和下载 GIF 动图的 Skill

## 1、Skill简介

这是一个能够快速搜索和下载 GIF 动图的 Skill，基于 Tenor API，支持命令行搜索、JSON 输出和 Markdown 格式展示。默认每次只返回一个最相关的 GIF，适合需要在聊天、文档或社交媒体中快速插入 GIF 表情的用户使用。

## 2、使用场景

### 为什么想做它？

在日常聊天和内容创作中，GIF 动图是表达情绪、活跃气氛的利器。但每次想找个合适的 GIF，都要：
- 打开浏览器搜索 GIF 网站
- 在大量结果中翻找
- 复制链接或下载
- 粘贴到需要的地方

这个过程太繁琐了，尤其是当你只是想快速找一个"点赞"、"鼓掌"或"可爱"的表情时。

### 之前遇到了什么麻烦？

- 手动搜索 GIF 耗时，经常要在多个网站间切换
- 搜索结果太多，选择困难
- 无法快速获取可直接使用的 URL
- 在命令行或代码环境中不方便操作

### 做出来之后能省掉哪些动作？

- 一句指令直接获取 GIF，无需打开浏览器
- 默认返回一个最相关的结果，避免选择困难
- 支持多种输出格式（Markdown、JSON、纯 URL）
- 可批量获取多个 GIF（通过 `--max` 参数）
- 标题智能优化，即使 API 无标题也能生成有意义的名称

## 3、创作过程

### 灵感来源

在使用 SOLO 平台时，我发现经常需要在对话中插入 GIF 来表达情绪或活跃气氛。但每次都得手动去 GIF 网站搜索，效率很低。我就想，能不能做一个 Skill，让我直接在命令行里搜索 GIF？

### 使用 SOLO 的创作步骤

1. **需求分析**：确定核心需求——搜索 GIF，默认返回一个结果，支持多种输出格式
2. **API 选择**：选择了 Tenor API（Google 旗下），免费且无需注册
3. **功能设计**：
   - 命令行参数解析（query、--max、--json、--format）
   - Markdown 格式输出（带标题、预览图、原图链接）
   - JSON 格式输出（便于程序化处理）
4. **标题优化**：实现智能标题生成逻辑，优先使用 API 标题，其次使用标签，最后使用搜索关键词
5. **输出调整**：默认只返回 1 个 GIF，避免信息过载
6. **测试验证**：多次测试不同关键词，确保输出稳定

### 关键代码

```python
def get_gif_title(result: Dict, query: str = "") -> str:
    """获取 GIF 标题，如果标题为空则从标签或搜索关键词生成"""
    title = result.get("title", "")
    if title and title.strip():
        return title.strip()
    
    tags = result.get("tags", [])
    if tags:
        return " ".join(t.capitalize() for t in tags[:3])
    
    if query:
        return f"{query.title()} GIF"
    
    return "GIF 动图"
```

### 技术架构

- **API 调用**：使用 Python requests 库调用 Tenor REST API
- **数据解析**：提取 id、title、url、preview_url、tags 等字段
- **格式输出**：支持 Markdown 表格、JSON、纯文本等多种格式
- **智能标题**：优先使用 API 标题 → 标签 → 搜索关键词

## 7、总结与思考

### 收获与感悟

创建这个 Skill 的过程让我深刻体会到：

1. **简单即美**：默认只返回一个结果，避免了"选择困难症"
2. **智能兜底**：即使 API 没有返回标题，也能通过标签或关键词生成有意义的标题
3. **灵活扩展**：支持多种输出格式，满足不同场景需求
4. **API 的力量**：善用免费 API，可以快速实现强大的功能

### 最满意的地方

最满意的是**智能标题生成**和**默认单结果**的设计。智能标题确保即使 API 数据不完整，用户也能看到有意义的结果描述；默认单结果则避免了信息过载，让用户专注于最相关的一个 GIF。

### 后续优化方向

1. **GIF 下载功能**：支持将 GIF 直接下载到本地
2. **多源支持**：集成 Giphy、Reddit 等更多 GIF 源
3. **TUI 预览**：在终端中预览 GIF（需要特定终端支持）
4. **收藏功能**：支持收藏喜欢的 GIF，方便后续使用
5. **静图提取**：从 GIF 中提取指定帧作为静态图片
